# Journal de déchiffrement

Carnet public et anonyme des découvertes faites en déchiffrement :
chiffres historiques, énigmes, challenges CTF, messages codés, etc.

## Organisation

| Dossier | Contenu |
|---|---|
| `chiffres/` | Les textes chiffrés bruts étudiés (un fichier par cible) |
| `decouvertes/` | Une fiche par découverte, basée sur `MODELE.md` |
| `outils/` | Scripts réutilisables (analyse de fréquences, César, Vigenère…) |

## Ajouter une découverte

1. Copier `decouvertes/MODELE.md` vers `decouvertes/AAAA-MM-JJ-nom-court.md`
2. Remplir : cible, méthode, résultat, niveau de confiance
3. Ajouter une ligne dans l'index ci-dessous

## Règles

- On ne publie que ce qu'on a le droit de publier : chiffres publics, énigmes,
  CTF, données qui nous appartiennent. Pas de données personnelles de tiers,
  pas de mots de passe, pas de contenu obtenu sans autorisation.
- Chaque découverte indique sa méthode, pour qu'elle soit vérifiable.

Voir `ANONYMAT.md` pour publier sans révéler son identité.
