# Handoff C1 — Générateur de mail de prospection

## Fait
- `app/outreach/compose.py` : le modèle rédige `subject`, `opening`, `closing` (mail J0),
  `text` (relance J+3, dernier message J+8, DM) ; le code assemble « Bonjour », les exemples
  (avis réel + réponse rédigée par le moteur B1 au nom du restaurant), la signature
  (`OUTREACH_SIGNATURE`) et la ligne d'opt-out. SMS et message de formulaire : modèles en code.
- Vérifications : 120 mots max (texte rédigé, hors avis cités), constat chiffré présent (regex
  sur les nombres, « 30 jours » exclu), « OK » présent, liste de formules génériques et de
  jargon (« solution », « IA », « e-réputation »…), vouvoiement. 2 tentatives avec retour.
- Choix des exemples : avis récents sans réponse, texte non vide, jamais un avis signalé par
  B2 ; un ≥ 4★ et un ≤ 3★ si possible. Le prix (`OUTREACH_PRICE_TEXT`) est passé au prompt.
- `repondu outreach-eval --limit 10` → `data/exports/eval-outreach-<date>.md` (DoD : relecture
  humaine, 0 faute, 0 formule générique).
- Tests : 17 (constat, chaque vérification, assemblage, retry, choix des exemples, éval).

## Non fait
- Aucun mail réel généré ici (pas de clé). Sur le VPS après A1–A4 : `repondu outreach-eval`.
- Les 120 mots excluent les avis cités : un mail complet avec 2 exemples fait ~200 mots.
  Si c'est trop long à la lecture, réduire à 1 exemple dans `build_examples(n=1)`.
